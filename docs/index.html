Configurable SNN classifier

Spiking networks for HiAER-Spike

This tool searches for spiking neural networks that can run on HiAER-Spike, a neuromorphic computer built at UC San Diego. You describe a family of networks with a few dozen settings. The tool rejects the ones the chip cannot hold, trains the rest with the chip's own arithmetic, and checks every result on a simulator of the chip.

The example task is recognizing 11 hand gestures filmed with an event camera. The most accurate network so far classifies 240 of 288 test clips (83.3%) on the chip simulator, against 68.75% in the HiAER-Spike paper. It needs more connections per neuron than the physical chip allows. The most accurate network that fits scores 79.2%.

1.1What HiAER-Spike is

HiAER-Spike is a neuromorphic computer, meaning one built to compute the way neurons in a brain communicate, with brief electrical pulses. It was developed at UC San Diego, runs on FPGAs, chips whose circuits can be reprogrammed after they are made, and is programmed from Python. A GPU runs a neural network by multiplying large matrices. HiAER-Spike instead stores every neuron and every connection between neurons individually, and it does work only when a neuron sends a spike. A spike is a single event: one neuron signaling to the neurons it connects to that it has fired.

The chip runs one specific kind of neuron, keeps its connections in tables of fixed size, and stores every number as a 16-bit integer. Each of these rules limits which networks can run on it. Together they are why a network trained the usual way cannot simply be copied onto the chip, and section 1.3 lists them.

1.2Spiking neurons, briefly

A spiking neuron keeps one number, its membrane potential. Time moves in discrete steps. At each step the neuron fires a spike if the potential is above a threshold θ (theta) and resets to zero, the potential leaks a little toward zero, and incoming spikes add their connection weights to it. The leak constant τ (tau) sets how fast the potential fades: each step it loses 1/τ of itself. This model is called leaky integrate-and-fire, or LIF, and it is the one HiAER-Spike implements.

A conventional network multiplies every input by its weight at every step, whether or not the input changed. A spiking network does work only where a spike arrives, one addition per spike per connection, so the work grows with activity. Counting those additions stands in for energy. Real energy use also depends on memory traffic and on the power the hardware draws while idle, which this project does not measure.

1.3The chip's rules

Five terms come up throughout the rest of the site.

synapse
One connection from one neuron to another, holding one weight.
axon
An input line that carries spikes into the chip from outside. Here the outside is an event camera.
fan-in
The number of connections arriving at one neuron.
fan-out
The number of connections leaving one neuron.
INT16
A signed 16-bit integer, from −32,767 to 32,767. Every weight and threshold on the chip is one.
RuleValueWhat it means for a network
input axons16,000Each input pixel needs one axon per channel. A 128×128 camera with two channels needs 32,768, so frames must be shrunk. The register can count to 16,383, but 16,000 is the most the current FPGA design has run.
fan-in8,159The most connections one neuron can receive. This is the limit networks break most often.
fan-out4,095The most connections one neuron can send (4,096 for an axon).
weightsINT16, |w| ≤ 1The integer 32,767 stands for 1.0, so weights lie in [−1, 1] in steps of 1/32,767, about 0.00003. A larger weight is clipped to 1.
threshold0 < θ ≤ 1Stored on the same grid as the weights.
leakτ = 2, 4, 8, 16, …The chip leaks by a bit shift, subtracting V >> k each step, so τ = 2k. Any τ that is not a power of two does not exist on the chip.
biasnone built inNeurons have no bias term. A bias can be added with a bias neuron: a neuron that fires on every step and connects to every neuron that needs the bias, at the cost of one connection each.
normalizationnoneNo batch normalization, the layer that rescales each channel during training so deep networks train reliably. Its effect is merged into the weights before deployment, a step called folding (page 4).
poolingfolded, or OR neuronsNo pooling operation. An average pool is folded into the next layer's connections, so every neuron in front of it connects straight to that layer, and a 2×2 pool multiplies that layer's fan-in by 4. A max pool of spikes asks whether any input fired, which one neuron with threshold 0 answers exactly, at the cost of one extra step.
update orderfire firstFire, reset, leak, then integrate (section 1.2). Each layer delays its output by one step.

1.4The example task: DVS128 Gesture

DVS128 Gesture is a dataset IBM published in 2017: 29 people performing 11 gestures, such as hand waves, arm rotations, air drums and air guitar, in front of an event camera. Each of the camera's 128×128 pixels reports when its own brightness changes, so moving edges produce events and a still background produces almost none, which suits a spiking network.

The data is split three ways. Training data teaches the network. A validation set, held back from training, is used to choose between networks. The test set is six people who never appear in training, scored once at the end, and it is the only score comparable to published results. Page B shows how recordings become frames and why the split is made by person.

1.5What the tool does

  1. Describe. A network is a list of settings: the layers, the neuron and the training recipe. For a search, each setting gets a range, and the tool samples a network from the ranges.
  2. Check. Before any training, the tool works out every layer's size and compares fan-in, fan-out and axon count against the chip's limits. This is arithmetic, so a network that cannot fit is rejected in microseconds.
  3. Train with the chip's arithmetic. Training uses a neuron that follows the chip's update order, integer weights, a power-of-two leak, and batch normalization folded in. The network that trains is the network that deploys.
  4. Check on the simulator. Every trained network runs clip by clip through a fast simulator that does the chip simulator's exact integer arithmetic, and is scored by what that simulator answers.
  5. Search. A sampler proposes configurations, many run at once, and weak ones stop early. The search keeps the network with the best deployed validation accuracy.

The tool builds convolutional classifiers, networks that slide small learned filters across an image, which is the standard design for image tasks. Page C follows one trial through every stage, and page 3 lists what the tool can build today and what extending it would involve.
