Configurable SNN Classifier · An Interactive Explainer

Teaching silicon to see
with spikes

A from-zero, interactive tour of a real research file (Practice2.py): a spiking neural network that recognizes hand gestures from an event camera, built to run on the HiAER‑Spike neuromorphic chip. No prior knowledge assumed — every concept gets a demo you can poke.

1.1What you're actually looking at

One Python file. ~3,200 deliberate lines. Four jobs:

  • Describe — a brain-inspired network where every knob (depth, kernels, channels, neuron physics, training recipe) is configuration, not hard-code.
  • Check — verify a proposed network physically fits the HiAER-Spike chip before wasting GPU time on it.
  • Train — teach it gestures in a way that already respects the chip's integer arithmetic.
  • Search — let an automated search try hundreds of configurations, hunting for >97.5% accuracy.

The accuracy that matters is measured on the version that actually runs on the chip — never the flattering floating-point version.

Why the obsession? The field's recurring disaster:

  • Train on a GPU → 95%. Convert for the chip → 60%.
  • The chip isn't broken. The trained network and the deployed network were quietly different networks.
  • Nearly every unusual decision in this code exists to make them the same network.

1.2The task: 11 gestures, one weird camera

The dataset: DVS128 Gesture (IBM, 2017). Watch a short clip of a person, name the gesture.

11 classes
clapping · left/right hand wave · each arm clockwise & counter-clockwise · arm roll · air drums · air guitar · "other"
the camera
A DVS (Dynamic Vision Sensor — an event camera). No frames. Each of its 128×128 pixels independently fires an event only when its brightness changes.
2 channels
ON = "got brighter", OFF = "got darker". That's why the data has C=2, not RGB's 3.
the signal
A stationary background produces silence. A moving hand produces a crackling stream of events tracing its outline. Sparse change — not pictures.
into the net
Events are chopped into T time-slices (usually 16), fed one slice at a time — details in chapter 5.

A sparse stream of change is exactly the signal spiking networks were born for. This camera-network pairing is a classic for a reason.

1.3Normal networks pass numbers. Spiking networks pass blips.

Two ways to build a "neuron":

ANN the networks you've heard of
  • Every neuron: weighted sum → squashing function → pass a precise decimal (0.7314…) onward.
  • Every neuron computes every time — interesting input or not. A giant calculator.
SNN this project
  • A neuron outputs nothing… or a spike: an all-or-nothing blip. 1s in a sea of 0s.
  • Its only memory is one number — the membrane potential — a leaky bucket of evidence.

The bucket's three rules:

  • Every incoming spike pours a little water in (how much = the connection's weight; inhibitory weights scoop water out).
  • The bucket leaks constantly — old evidence fades. The leak speed is set by a constant called tau (τ).
  • If the water level crosses a threshold (θ), the neuron fires a spike of its own to everyone downstream, and the bucket empties (a reset).

That flavor is called LIF — Leaky Integrate-and-Fire — the only neuron type this codebase deploys. Two enormous consequences follow from "output is 0 or 1":

  • Time is part of the computation. A single spike says almost nothing; how often and when a neuron fires carries the information. The network must be run for T timesteps and its output spikes counted.
  • Silence is free. When nothing spikes, downstream neurons do no work — no multiply, no add, nothing. Sparse input ⇒ tiny energy. This is why neuromorphic chips can run on milliwatts.

1.4The catch: the chip is a harsh landlord

Spikes-are-cheap only pays off on hardware built for spikes. The target: HiAER‑Spike (UC San Diego, Hierarchical Address-Event Routing), programmed via hs_api.

A GPU runs whatever math you write. This chip has house rules the code treats as physics:

LIMITS Wiring budgets

A neuron may listen to at most 8,159 other neurons (fan-in) and shout to at most 4,095 (fan-out). The input side gets 16,383 total input lines ("axons"). Design a layer that exceeds these and it cannot be wired up, period. Chapter 4 lets you trip these limits yourself.

INTEGERS No decimals on chip

Weights live on a 16-bit integer grid and are hard-clamped to [−1, +1] — a weight of 1.3 silently becomes 1.0. Thresholds become integers. Even the leak τ is an integer register: τ=2.1 and τ=2.4 deploy as the same network. Training must anticipate all of this.

Plus one subtlety that silently costs accuracy if ignored:

  • The chip's neuron fires based on the previous timestep's bucket level — a different internal order than the standard software neuron.
  • Result: every layer delays the signal by one tick, like a bucket brigade.
  • So a 5-layer network needs 5 extra "flush" timesteps of empty input after the clip ends — or the final frames' evidence never reaches the output.
  • The code models this during training, so there are no surprises on chip (chapter 2 animates it).

1.5The whole system in five boxes

Everything in the file serves this pipeline. Click any box to jump to its chapter.

STAGE A
Event camera
128×128 DVS sensor streams sparse ON/OFF brightness-change events. Chopped into T=16 time-slices, shrunk to 64×64, snapped to 0/1.
STAGE B
Configurable SNN
A few convolution layers of LIF neurons + a tiny classifier head. Depth, kernels, channels, pooling — all knobs. Planned & feasibility-checked before building.
STAGE C
Training
Backpropagation with a "surrogate gradient" trick, warmup in float, then training on the chip's integer grid (quantization-aware training).
STAGE D
Fold & quantize
BatchNorm gets mathematically absorbed into conv weights; weights snap to INT16 in [−1,1]; biases hide inside per-channel thresholds. Deployability is checked, not hoped for.
STAGE E
The search
Optuna + Ray Tune try hundreds of configs. Free feasibility check first, cheap float training with early stopping, and the chip-accurate number is what gets optimized.

  • Design rule worth noticing: sections 1–4 import no PyTorch — pure Python math.

  • The heavy machinery only loads when you actually train.
