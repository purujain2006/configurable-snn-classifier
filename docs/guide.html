2What the tool can build today

The goal is a tool that takes any convolutional network and finds a version of it that runs well on HiAER-Spike. Today it builds one family: a straight stack of convolution layers with a classification head, described by settings.

You want toSupported todayWhat it would take
Change a convolutional classifierYes: depth, per-layer kernels and channels, pooling or strides, neuron settings, the head, bias neurons.Pick settings the planner can express. The chip check and the simulator check run automatically.
Use another image or event datasetYes: built-in loaders, or your own file that returns the datasets.Return the train and test sets with the image size and class count, and pick an input coding (page B).
Load an existing PyTorch modelNo. The tool builds its own model from settings.Describe the model as settings, or add an importer that turns a PyTorch model into the planner's layer list.
Use residual connections, attention or recurrenceNo. The planner and the exporter handle a straight sequence of layers.Extend the planner from a sequence to a graph, decide how branches line up in time (each layer adds one step of delay), and add each operation to the exporter and the simulator.
Do detection, segmentation or regressionNo. The head, the loss and the accuracy measure assume classification.Add the task's outputs, loss and measures.
Target a different chipNo. The neuron, the number formats and the exporter are specific to HiAER-Spike.Replace the limits, the neuron arithmetic and the exporter, and test against that chip's own simulator.
