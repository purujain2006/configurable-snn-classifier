Its output neurons need 32,256 connections each; the limit is 8,159.

The best network has two convolution layers: 81 channels with a 3×3 kernel, then 56 channels with a 5×5 kernel, each followed by a 2×2 average pool, on 48×48 frames with 16 frames per clip. On the simulator it classifies 240 of the 288 test clips correctly. Its PyTorch model and the simulator predict the same gesture on every one of the 464 validation and test clips.

Two things had to change before that match. The network had learned τ = 3 in every layer, which the chip cannot run (section 2.3), so it runs at τ = 4, which leaves test accuracy at 83.3%. And it does not fit the chip's fan-in limit, because the search that found it counted fan-in after pooling (section 4.1). The best network that does fit is 79.9% (section 7.3).

The paper's models use different input sizes and were measured on the FPGA, so the 14.6-point gap compares two different setups, not two equivalent ones.

How these numbers were measured

Training data fits the weights. Validation data (176 clips for these runs) chooses between networks and checkpoints. Test data is 288 clips from six people who never appear in training, and it is the only number comparable to published work.

For these runs, validation clips were drawn at random from the training people, so validation shared people with training and ran high: 0.92 on validation against 0.83 on test for the best network. Validation now holds out whole people (section 5.1). The five networks below and the weight-decay runs were each scored on test, so test results have also guided which experiments came next.

7.2The search that found it

The search tried 400 configurations, sampling each layer's settings separately and training each for up to 60 epochs. It ranked finished trials by validation accuracy after export to 16-bit integers.

The five networks with the best validation scores were trained again for 300 epochs, with weight decay 0.001. All five use two convolution layers (3×3, then 5×5), 48×48 input, 16 frames, no hidden head layer, and an average pool after the first layer. Two of the five fit the chip: ranks 4 and 2, at 79.9% and 78.8% test. Both pool once and stride the second layer. They trained before τ was limited to powers of two, so their τ still needs checking.

Rank 1 is the most accurate and also the most active: 50.1 million SynOps per clip, against 18 to 23 million for the others. Its 0.73× ratio only says it does fewer operations than a conventional network of its own shape; each row's ratio has a different denominator, so the ratios cannot rank the networks against each other. If operation count matters, rank 3 classifies 232 clips correctly with 20.3 million SynOps, eight fewer clips than rank 1 for 40% of the work.

Each row is one training run of one network. Repeating each with different random starting weights would show how much of the gap between rows is chance.

7.4What weight decay did

Weight decay pulls parameters toward zero during training, which can reduce overfitting and, in a spiking network, lower firing. The rank-1 network was trained three times for 300 epochs, changing only the weight decay. At the time, weight decay also applied to τ, so the last column shows the τ each layer learned, starting from 8.

Raising weight decay from 0.000096 to 0.001 cut SynOps by 37% and gained three test clips. At 0.01 the network stopped fitting its training data (80% training accuracy) and test accuracy fell below the paper's.

The τ column complicates the reading. As weight decay rose it drove τ down, and a smaller τ makes neurons forget faster and fire less, so part of the drop in SynOps may come from τ and not from the weights. Weight decay no longer touches τ, so repeating this sweep would separate the two effects.

No run showed a late jump in test accuracy after training accuracy had flattened (sometimes called grokking) within 300 epochs. Training accuracy levelled off near epoch 80.

7.5Settings the search could not judge

Optuna samples settings that look promising more often, so a setting that started badly can end up barely tested. In the search above:

  • GAP heads. 32 of the 400 configurations used GAP, and none finished: every one was stopped early. Early stopping judges trials at 10 epochs, and GAP networks may simply learn more slowly, so the search gives no verdict on GAP.
  • Dropout inside the convolution layers. Used in 44 of the 318 networks that fit, and only 12 of those finished.
  • A penalty on firing rate. Used in 24, of which 1 finished. The penalty also applied to the output layer, whose spikes are the prediction, which worked against the classification loss. It now skips the output layer.

The next search forces convolution dropout and the firing-rate penalty on in every trial so they get a fair test.

7.6How far to trust these numbers

  • Each network was trained once. Without repeated runs there is no measure of how much a score moves by chance, and the five networks above sit within a few points of each other.
  • Validation shared people with training, so validation scores ran about 9 points above test.
  • Test results have guided which experiments came next, so test accuracy has partly been used for selection.
  • Scores come from the simulator. Energy, timing and accuracy on the physical FPGA have not been measured.

tools/hpo_analysis.py measures which settings moved accuracy across the search, with corrections for testing many settings at once. Optuna's adaptive sampling makes settings move together, so those associations suggest experiments without proving causes.
