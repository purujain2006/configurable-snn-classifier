Glossary

Every term, in plain words

Each term below is underlined with dots the first time it appears on a page, and pointing at it there shows this definition. Most also say why the thing exists, meaning the problem that led someone to invent it. The link after each one goes to where the site explains it in full.

A

accuracy
The fraction of clips a network classifies correctly. 0.745 of 216 clips is 161. Page B
activation function (ReLU)
The rule that turns a neuron's sum into its output. ReLU keeps a positive sum and turns a negative one into zero. Page AWhy it existsWithout a rule that bends the sum, any stack of layers would collapse into one big multiplication and could only learn straight-line patterns.
Adam and AdamW
The most common optimizer. Adam uses momentum and divides each weight's step by the size of that weight's recent gradients, so every weight moves at a similar pace. AdamW applies weight decay to the weights directly instead of through the gradient. Page AWhy it existsOne learning rate for all weights is too large for some and too small for others. Scaling each weight's step by its own gradient history fixes most of that without tuning.
address event
A spike sent as a short message holding only the address of the neuron that fired. The receiver looks up that neuron's connections itself. Page 0Why it existsA spike carries no value, only the fact that it happened, so the sender's address is all the message needs. Short messages keep the traffic between cores small.
ANN
An ordinary neural network, whose neurons pass exact numbers to each other. Page AWhy it existsThe kind of network almost all software uses today. GPUs run it fast by multiplying large tables of numbers.
arctangent
Another S-shaped curve. Its slope is the surrogate gradient used here. Page A
ASHA
An early-stopping rule. At a checkpoint, trials are ranked and only the best third continue. Page CWhy it existsMost weak trials are already clearly behind early on. Stopping them frees GPUs for promising ones, so a search covers more networks in the same time.
augmentation
Making new training examples by changing old ones in ways that keep their label, such as shifting a clip a few pixels. Page BWhy it existsThe dataset is small, and a network can memorize a small dataset. Varied copies show it more ways a gesture can look.
axon
An input line that carries spikes into the chip from outside. The chip has 16,000, so the input frame must be small enough to fit. Page HomeWhy it existsSpikes from outside, such as camera events, need a way in. Every input line takes up chip resources, so their number is fixed, and the input frame has to fit within it.

B

backpropagation
The method that computes every weight's gradient at once by working backwards from the output. Page AWhy it existsComputing each weight's gradient separately would take one pass through the network per weight. Working backwards from the output reuses shared results, so every gradient together costs about one extra pass.
balanced block
The first 96 trials of a search, designed so every option appears equally often, and never stopped early. Page CWhy it existsOptuna's own trials follow its guesses, so they test some options often and others rarely. A balanced block first gives every option an equal, fair test, so options can be compared.
batch
The small group of examples used for one training step: 16 clips here. Page AWhy it existsOne example gives a noisy direction, and all of them take too long per step. A small batch is a cheap and fairly reliable middle ground.
batch normalization (BN)
A training step that holds each channel's values in a steady range. It subtracts the channel's average over the batch, divides by its spread, then applies a learned scale and shift. After training it is a fixed multiply and add, which is folded into the weights and thresholds before deployment. Page AWhy it existsWithout it, the size of each layer's activity drifts during training, and deep networks train slowly or stall. Rescaling keeps every layer in a workable range.
bias
A number a neuron adds on its own, whatever its inputs. The chip has none built in, so a bias is folded into the threshold or delivered by a bias neuron. Page AWhy it existsWith a bias, a neuron can shift the point where it starts to respond, whatever its inputs.
bias neuron
A chip neuron that fires on every step. Its connections deliver a constant bias to the neurons it feeds, at the cost of one connection each. Page GWhy it existsChip neurons have no bias input of their own, but they do have connections. A neuron that always fires turns a constant push into ordinary connections.
binarize
Turn numbers into all-or-nothing spikes, which rounds them. Page AWhy it existsThe chip passes only spikes between neurons, so every value between layers has to become one.
bit
A binary digit, 0 or 1. With B bits a number can go from 0 to 2^B − 1: 1 bit gives 0 or 1, 4 bits give 0 to 15. Page E
bit shift
Moving a binary number's digits one place to the right, which halves it. It is the cheapest division a chip can do. Page FWhy it existsA full divider circuit is large and slow, and a shift is nearly free, so the chip computes its leak with one.

C

channel
One of several stacked pictures. The camera gives two (brighter and darker events), and each layer makes one per kernel. Page A
checkpoint
A point in training, epoch 30 here, where early stopping compares trials and stops the weaker ones. Page C
classifier
A network, or its last layer, that picks one answer out of a fixed list of classes, here the 11 gestures. Page A
clip
One recording of one gesture. Page B
clipping
Cutting a value that is too large down to the largest storable one. A weight of 1.3 is stored as 1.0. Page GWhy it existsEvery storable range has a top. Clipping keeps an oversized weight usable at the cost of changing its value.
CNN
A convolutional neural network, built from convolutions. It is the standard design for pictures. Page A
configuration
One full set of settings that describes a network and how to train it. Page C
convolution
Sliding a small grid of weights across a picture and adding up what lies under it at every position, so the same pattern is found anywhere in the image. Page AWhy it existsA gesture looks the same wherever it happens in the picture. Reusing one small grid of weights at every position finds a pattern anywhere, with far fewer weights than connecting every pixel to every neuron.
cutout
An augmentation that blanks out one square of the picture. Page B

D

dataset
A collection of recorded examples to learn from and test on. Page B
dense
Doing every multiplication whether or not the input carries anything, as an ordinary network does. Page A
deploy
Put on the chip and run there. A deployable network fits every chip limit and passed the simulator check. Page CWhy it existsThe goal of the whole project is a network that runs on the chip with the accuracy measured for it.
dropout
Silencing a random set of units during training, so the network cannot rely on any single one. Page A
DVS128 Gesture
The dataset used here: 1,464 event-camera recordings of 29 people performing 11 hand gestures. Page BWhy it existsIt is a standard benchmark recorded with an event camera, so results here can be compared with other spiking-network work.

E

early stopping
Ending a trial before its full training run because it is clearly behind the others. Page C
epoch
One pass through all of the training data. A trial here trains for up to 80 epochs. Page A
event
One report from an event camera pixel, saying where, when, and whether it got brighter or darker. Page B
event camera (DVS)
A camera whose pixels each report the moment their own brightness changes, instead of sending whole pictures. Page BWhy it existsMost of a scene stays still most of the time. Reporting only changes saves data and power and catches fast motion, and the output already looks like spikes, a natural match for a spiking chip.
export
Writing a trained network out in the chip's own format, as tables of neurons, connections, integer weights and thresholds. Page CWhy it existsTraining happens in software that thinks in layers of decimal numbers, and the chip thinks in single neurons, connections and whole numbers. Export translates one into the other.

F

fan-in
How many connections arrive at one neuron. The chip allows at most 8,159. Page GWhy it existsEach neuron's incoming connections live in a table of fixed size, which keeps every lookup fast and the circuit simple. The table's size sets the limit.
fan-out
How many connections leave one neuron. The chip allows at most 4,095. Page GWhy it existsEach neuron's outgoing connections also live in a table of fixed size, for the same reason as fan-in.
feature map
The picture a kernel produces. It is bright wherever the input looks like the kernel. Page A
finalists
The best few configurations of a search, trained again with new seeds before a winner is named. Page CWhy it existsThe best score out of hundreds of trials is partly luck. Retraining the best few with new seeds shows which ones are really good.
firing rate
How often neurons fire. A firing-rate penalty adds it to the loss, so the network learns to fire less and do less work. Page AWhy it existsEvery spike costs energy on the chip. Fewer spikes means less work, so the penalty trades a little accuracy for a lighter network.
flatten
Laying every cell of every map out in one line, so the classifier knows where each feature appeared. Page A
flush steps
Extra empty steps after the last frame, one per layer, so the evidence from the last frames can still reach the output. Page AWhy it existsEach layer passes its spikes on one step later, so evidence from the last frame needs one extra step per layer to reach the output.
folding
Merging one operation into another so the chip does not have to run it, such as batch normalization into the weights and thresholds, or an average pool into the next layer's connections. Page GWhy it existsTraining uses operations the chip lacks, such as batch normalization. Folding absorbs them into weights and thresholds, which the chip does have, so the network computes the same thing without them.
forward pass
Running one input through the network, layer by layer, to get an answer. Page A
FPGA
A chip whose circuits can be reprogrammed after it is made. HiAER-Spike is built from them. Page HomeWhy it existsA custom chip takes years and a fortune to design and manufacture. An FPGA lets a new chip design run in real hardware now and be improved later.
frame
One slice of a recording, holding the events from a short stretch of time. A clip of T frames runs for T steps. Page BWhy it existsEvents arrive at any instant, so grouping them into short slices is what gives the network one input per step.

G

GAP (global average pooling)
Averaging each map down to one number, so the classifier knows how much of each feature there was but not where. Page AWhy it existsFlattening hands the classifier one input for every cell of every map, which makes it large and lets it memorize where things happened. Averaging hands it one number per channel.
GPU
A graphics processor, the chip that trains neural networks quickly by doing many multiplications at once. Page CWhy it existsTraining is mostly huge multiplications of tables of numbers, which a GPU does thousands at a time.
grace period
How long a trial trains before early stopping may judge it: 30 epochs here. Page CWhy it existsSome good networks start slowly. A grace period keeps them from being cut before they can show it.
gradient
For each weight, which way to nudge it to make the loss smaller, and how strongly. Page AWhy it existsWith thousands or millions of weights, trying changes one at a time is hopeless. The gradient says which way to move every weight at once.
gradient clipping
Capping how large one update can be, so one unusual batch cannot throw the weights far off. Page AWhy it existsAn occasional very large gradient can undo many good steps at once.
gradient descent
Training by repeatedly moving every weight a small step in the direction that lowers the loss. Page A
grokking
A sudden late improvement on new data, long after training accuracy has flattened. Page H

H

head
The last part of the network, which turns the feature maps into one score per class. Page A
HiAER-Spike
The neuromorphic computer this tool targets, built at UC San Diego. It stores every neuron and connection individually and runs on FPGAs. Page HomeWhy it existsMade to run large spiking networks on real hardware, outside a simulation. Its name, Hierarchical Address-Event Routing, describes how spikes travel, as short address messages through levels of routers.
hidden layer
A layer between the input and the output. Page A
hyperparameter
A choice made before training, such as a layer's width or the learning rate. This site mostly calls them settings. Page CWhy it existsTraining learns the weights, but someone still has to choose the network's shape and how to train it. These choices change accuracy a lot, and the usual training method cannot learn them.
hyperparameter search
Trying many configurations automatically, training each one, and keeping the best. Page 0Why it existsThere are too many combinations of settings to test by hand, and they interact, so the best value of one setting depends on the others.

I

INT16 (16-bit integer)
A whole number stored in 16 bits, from −32,767 to 32,767. Every weight and threshold on the chip is one, with 32,767 standing for 1.0. Page GWhy it existsThe chip stores one weight for every connection. Sixteen bits per weight halves the memory of the 32-bit decimals networks usually train with and keeps the adding circuits small.
integer
A whole number, with no fraction. The chip stores every weight, threshold and potential as one. Page G
integer grid
The evenly spaced values the chip can store. A weight on the grid is a whole number of steps of 1/32,767. Page C

K

k-fold cross-validation
Splitting the training people into k groups and training k times, each time holding out a different group for validation, so every person is held out once. The score is the average over the k runs. Page BWhy it existsOne fixed validation set is one draw of people. If the draw is hard or easy, every score reads low or high, and k-fold averages that luck out.
kernel
The small grid of weights a convolution slides across the picture, for example 5 × 5. Page A

L

label smoothing
Training toward a target that gives the right answer slightly less than 100%, which discourages overconfidence. Page A
layer
A group of neurons that read the same inputs and pass their outputs on together. Page A
leak (τ)
How fast a spiking neuron's potential fades, set by τ (tau). Each step it loses 1/τ of itself. On the chip τ must be a power of two. Page AWhy it existsOld input fades, so the neuron responds to what is happening now more than to what happened long ago.
leaky integrate-and-fire (LIF)
The spiking neuron used here. Each step it fires if its potential is above the threshold, resets, leaks, then adds its new input. Page AWhy it existsThe simplest neuron model that keeps three behaviors of real neurons. It adds up input, slowly forgets and fires. It is simple enough to build in large numbers on a chip.
learning rate
How big each training step is. Too small wastes time, and too large overshoots and bounces around. Page AWhy it existsA gradient gives a direction but no distance. The learning rate sets the distance.
learning-rate schedule
A rule for changing the learning rate over a run, usually from larger to smaller, for example smoothly (cosine) or in stages (step). Page AWhy it existsLarge steps make fast progress early but bounce around near the best point, and small steps settle in. A schedule gets both.
log scale
A scale where each step multiplies instead of adds, so 0.001, 0.01 and 0.1 are evenly spaced. Page 0Why it existsSettings such as the learning rate matter by factors of ten, so on a log scale 0.0001 to 0.001 gets as much room as 0.001 to 0.01.
loss (cross-entropy)
One number that says how wrong the network's answers were. Training tries to make it smaller. Cross-entropy is the usual loss when the answer is one of several classes. Page AWhy it existsTraining needs one number to push down. The loss sums up how wrong the network was, across every example, as that number.
loss landscape
A picture of the loss for every possible setting of the weights. Training walks downhill on it. Page A

M

membrane potential
The one number a spiking neuron keeps. It rises with input, leaks over time, and the neuron fires when it passes the threshold. Page AWhy it existsIt gives the neuron a memory over time, so input arriving across several steps can add up to one spike.
momentum
Stepping along a running average of recent gradients instead of the latest gradient alone, so consistent directions build up speed and back-and-forth bouncing cancels out. Page AWhy it existsIn a long, narrow valley, plain gradient descent bounces between the walls and crawls along the floor. Momentum keeps the progress along the floor.
multiply-add (MAC)
One multiplication and one addition, the unit of work in an ordinary network. Page AWhy it existsIt is the matching unit of work for ordinary networks, so the two kinds of network can be compared.

N

neural network
A program made of many small calculations, called neurons, connected in layers. It learns its behavior from examples instead of being written by hand. Page AWhy it existsMany tasks, such as recognizing a gesture, are too hard to write down as rules. A network learns the rule from labeled examples.
neuromorphic
Built to compute the way brains do, with many simple neurons that send brief spikes to each other, doing work only when a spike arrives. Page HomeWhy it existsOrdinary computers keep memory and processor apart and spend most of their energy moving numbers between them. Brains keep memory beside the neurons and work only when a spike arrives, so a chip built the same way can run a network on far less energy.
neuron
One small calculation in a network. It adds up its inputs, each multiplied by a weight, and decides what to pass on. Page A

O

optimizer
The rule that turns gradients into weight changes. Plain gradient descent, momentum and Adam are three such rules. Page AWhy it existsPlain gradient descent moves every weight with the same step size, which is slow when some weights need large moves and others small ones. Adam and AdamW set each weight's step from its own recent history.
Optuna
A library that proposes which configuration to try next, from the scores of finished trials. Page CWhy it existsThere are far too many combinations of settings to try them all. Optuna spends the trials where the results so far look promising.
OR neuron
A chip neuron with threshold 0 that fires if any of its inputs fired. It runs a max pool of spikes exactly, one step late. Page GWhy it existsThe chip has no max operation. For spikes, the largest of several inputs is 1 exactly when any of them fired, which one ordinary neuron can compute.
overfitting
Learning the training examples too well, including details that do not carry over to new ones. It shows as a gap between training and validation accuracy. Page B

P

padding
A border of zeros added around a picture so a kernel can reach its edges. Page GWhy it existsWithout it, every convolution would shrink the picture, and pixels at the edge would be seen less often than ones in the middle.
parameter
A number that training learns, such as a weight. A convolution reuses its parameters at every position, so it has far fewer parameters than connections. Page G
Pareto
Keeping every network that no other network beats on both accuracy and work at once. Page GWhy it existsAccuracy and work pull against each other, so there is no single best network. The Pareto set lists every network worth considering for some balance of the two.
percentage point
The difference between two percentages. Going from 74% to 76% is 2 percentage points. Page B
pipeline
The fixed sequence of stages every candidate network passes through, from its settings to a score on the chip simulator. Page CWhy it existsEvery candidate has to be judged the same way, from its settings to its chip score, or comparing them means nothing.
planner
The step that works out every layer's size from a network's settings, once, for everything else to read. Page GWhy it existsTraining, the chip-limit checks and export all need the layer sizes. Working them out once keeps every stage in agreement.
Poisson coding
A random way to turn brightness into spikes. Each step, a pixel fires with probability equal to its brightness. Page B
polarity
Whether an event was a brightening or a darkening. The two polarities become the input's two channels. Page B
pooling
Shrinking a map by replacing each 2 × 2 block with one number, either its average (average pool) or its largest value (max pool). Page AWhy it existsSmaller maps cut the work of every later layer and let later layers combine evidence from a wider area.
power of two
One of 1, 2, 4, 8, 16 and so on. The chip's leak τ must be one, because the chip computes the leak with a bit shift. Page FWhy it existsDividing by a power of two is a bit shift, which costs almost nothing in a circuit. Any other τ would need a divider in every neuron.
preflight
A run of every stage of a search in miniature, about 15 minutes, which must pass before the real search may start. Page CWhy it existsA mistake found deep into a large search wastes all the GPU time spent so far. A miniature run of every stage finds it in minutes.
Python
A programming language. The tool is written in it. Page this site
PyTorch
The deep-learning library the training runs in. Page F

Q

quantization
Rounding numbers to the limited set of values a chip can store. Page GWhy it existsSmall numbers save chip memory and energy, so a trained network's exact weights have to be rounded to fit. Rounding changes the answers a little, which is why accuracy is measured after it.

R

rate loss
Scoring a spiking network by its output spike counts over the whole clip, turned into probabilities with softmax and scored with cross-entropy. It is what the chip reports. Page AWhy it existsThe chip answers by counting spikes, so scoring the counts trains the network on exactly the answer it will give.
Ray Tune
A library that runs many trials at once on the available GPUs and collects their reports. Page CWhy it existsEach trial takes a long time to train. Running many at once on the available GPUs finishes a search much sooner.
reduction factor
How harshly early stopping cuts. With a factor of 3, about one trial in three continues past a checkpoint. Page C
regularization
Any setting that makes memorizing the training examples harder, to close the gap between training and validation accuracy. Page AWhy it existsA network with many weights can memorize a small dataset. Making memorizing harder pushes it toward what carries over to new people.
repository
The project's code and files, kept on GitHub. Page this site

S

sampler
The part of Optuna that proposes the settings of the next trial. Page C
seed
A number that fixes every random choice of a training run, so the same seed repeats a run exactly. Page CWhy it existsTraining is full of random choices, so two runs with the same settings can differ by luck. A fixed seed makes a run repeatable, and several seeds measure the luck.
sigmoid
An S-shaped curve that turns any number into one between 0 and 1. Page F
signed spikes
Spikes that can be +1 or −1. On the chip each signed unit is two neurons, one for each sign. Page AWhy it existsAn ordinary spike can only push the next neuron one way. A negative spike lets one unit carry negative values too, at the cost of two chip neurons per unit.
simulator
A program that computes exactly what the chip would. Every trained network is checked on one, clip by clip. Page CWhy it existsRunning every candidate on the physical chip would be slow and needs the hardware. The simulator gives the chip's exact answer on an ordinary computer, so every trained network is checked, and any mismatch with training shows up early.
softmax
A function that turns a list of scores into probabilities that add up to 100%. Page AWhy it existsRaw scores can be any size. Probabilities let the loss compare the network's confidence with the right answer.
spike
A single all-or-nothing signal. At each step a neuron either fires or it does not. Page AWhy it existsOne bit is the smallest possible message, and sending nothing costs nothing, so a neuron that talks in spikes only uses energy when it has something to say.
spiking network (SNN)
A network whose neurons pass spikes instead of numbers and run step by step through time. Page AWhy it existsSpikes let a chip do work only when something happens, which can save a great deal of energy. Spiking networks are the networks such chips can run.
SpikingJelly
A PyTorch library for spiking networks, which the training code builds on. Page F
standard error
How far an average could move by chance. It is the spread of the values divided by the square root of how many there are. Averages closer than about two standard errors are a tie. Page BWhy it existsAn average over a few runs still carries luck, and the standard error says how much.
straight-through estimator
Passing the gradient through a rounding step as if the rounding were not there. Page AWhy it existsRounding, like a spike, has no useful slope. Ignoring it on the way back lets training continue while the network itself still rounds every value it passes on.
stride
How far a kernel moves at each step. A stride of 2 roughly halves the size of the map. Page AWhy it existsMoving the kernel in bigger jumps shrinks the picture as it goes, so later layers cost less work and each of their cells covers more of the scene.
surrogate gradient
A smooth stand-in for the slope of a spike, used only while computing gradients, so a spiking network can be trained. Page AWhy it existsA spike jumps from 0 to 1, so its slope is zero almost everywhere and undefined at the jump, and training by gradients gets nothing from it. Borrowing a smooth curve's slope lets the usual training method work.
synapse
One connection from one neuron to another, holding one weight. Page HomeWhy it existsThe chip stores each connection separately, so connections are what fill its memory, and what the fan-in and fan-out limits count.
SynOp (synaptic operation)
One spike adding one weight to one neuron, the unit of work on a spiking chip, used as a stand-in for energy. Page AWhy it existsMeasuring a chip's energy directly needs the chip and special equipment. Counting spike deliveries gives an estimate without either, and research papers use the same count, so results can be compared.

T

tdBN
Threshold-dependent batch normalization, a version of batch norm made for spiking networks. It works out one average and spread over all the timesteps of a clip together, and sizes its output relative to the neuron's threshold. Page AWhy it existsPlain batch norm treats every timestep separately and ignores the threshold, so a spiking layer can end up mostly silent or firing all the time. tdBN keeps a typical input about the size of the threshold.
test set
Examples kept aside until the very end and scored once: 288 clips from 6 people never seen in training. Page BWhy it existsEvery choice made by looking at a set of clips bends the result toward those clips. A set scored once, at the very end, gives an honest estimate for new people.
TET
Temporal efficient training, a loss for spiking networks that scores the output at every step and averages, instead of scoring only the spike count over the whole clip (the rate loss). Page AWhy it existsScoring only the total lets a network be right late and wrong early. Scoring every step pushes it to be right throughout, which tends to train spiking networks better.
threshold (θ)
The potential a spiking neuron must exceed to fire, written θ (theta). On the chip it lies between 0 and 1. Page AWhy it existsIt turns a gradually changing total into an all-or-nothing spike.
timestep
One tick of the clock in a spiking network. Every layer updates once per step. Page AWhy it existsThe chip updates its neurons on a clock, and training simulates the same ticks so the two agree.
tmux
A program that keeps a command running on a server after you log out. Page this siteWhy it existsA search runs for days, far longer than any login session.
TPE
Optuna's method. It proposes values that were common among the best trials and rare among the rest. Page C
training set
The examples the network learns from. Page B
trial
One candidate network the search builds, trains and scores. Page CWhy it existsThe search learns which settings work by training many candidates and comparing them.

V

validation set
Examples held back from training and used to choose between networks. Here it is 216 clips from 4 people. Page BWhy it existsChoosing among networks needs a score on clips they never trained on, and the test set has to stay untouched until the end.
variance
How spread out a set of numbers is, measured as the average squared distance from their mean. Page G
von Neumann bottleneck
The limit an ordinary computer hits because its memory and processor are separate. Every number has to travel between them, and the trip costs more time and energy than the arithmetic. Page 0Why it existsNearly every computer follows the design John von Neumann described in 1945, with memory and processor apart, because then one machine can run any program. This bottleneck is the price of that design, and neuromorphic chips avoid it by keeping memory beside the neurons.

W

warm-up
The first stretch of a run. In training here, the first quarter of the epochs on ordinary weights. In a learning-rate schedule, it is a few epochs where the rate ramps up from small. Page CWhy it existsTraining with exact weights first lets the network find a good region before rounding is switched on, which trains more reliably than rounding from the start. A learning-rate warm-up avoids large, wild steps from a random start.
weight
A number on a connection that says how strongly one neuron's output pushes the next neuron, and in which direction. Learning means adjusting weights. Page A
weight decay
A small pull of every weight toward zero on each step, which discourages memorizing. Page A

Y

YAML
A plain-text file format for settings, one setting per line. Each search is described by one. Page this site
